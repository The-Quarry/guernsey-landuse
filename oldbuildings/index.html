    Where the changes are

    Applications granted since the Island Development Plan took effect (November 2016 onwards), by parish, with the number of homes they allow. Most are in the north, where the island's vineries were concentrated.

    How this map was made

    The applications

    Each description was read for two kinds of change: converting an existing building that was not a home (a packing shed, barn, stable, store or outbuilding) into one or more homes, and demolishing such a building to put up a house or flats in its place. Building a new house next to a working shed, converting an outbuilding into an annexe for an existing house, and replacing one house with another are all left out. Amendments to earlier approvals are left out so the same scheme isn't counted twice. Former hotels and self-catering units are on the hotels map instead.

    The sorting is done on the wording of each description. A random check of 25 included applications found one that may not belong (a boiler house converted to a store as part of a wider scheme). Treat individual counts as close rather than exact.

    Homes

    The number of homes comes from the description where it gives one ("convert agricultural building to 4 dwellings"). Where it doesn't, the application is counted as one home. A permission is not proof the home was built: some lapse, and the same site often appears more than once as schemes are revised.

    Dates and outcomes

    Each application appears in the month it was validated, not the month it was decided. The outcome is its status on the register now, so recent months include applications still pending.
